Согласие на обработку персональных данных

Настоящим я даю своё согласие на обработку персональных данных

1.1. 2. Персональные данные, на обработку которых даётся согласие

2.1. Настоящее согласие предоставляется на обработку следующих персональных данных:

  • Фамилия, имя, отчество
  • Адрес электронной почты (e-mail)
  • Номер телефона
  • Дата рождения
  • Пол
  • Фотографии (при их предоставлении в рамках участия в программах)
  • Данные о физических параметрах (вес, рост, объёмы тела)
  • Информация о состоянии здоровья, необходимая для составления индивидуальной программы тренировок и питания
  • Иные данные, предоставленные мной в процессе использования сервисов Сайта

3. Цели обработки персональных данных

3.1. Персональные данные обрабатываются Оператором в следующих целях:

  • Регистрация и идентификация пользователя на Сайте
  • Предоставление доступа к функционалу Сайта и оказание услуг
  • Разработка индивидуальных программ тренировок и питания
  • Проведение онлайн-консультаций и персонального сопровождения
  • Отслеживание прогресса и результатов клиента
  • Обработка платежей за услуги
  • Информирование об услугах, акциях и спецпредложениях
  • Техническая поддержка и коммуникация с клиентом
  • Анализ и улучшение качества услуг
  • Выполнение обязательств перед клиентом

4. Способы обработки персональных данных

4.1. Оператор обрабатывает персональные данные следующими способами:

  • Сбор, запись, систематизация, накопление, хранение
  • Уточнение (обновление, изменение)
  • Извлечение, использование, передача (распространение, предоставление, доступ)
  • Обезличивание, блокирование, удаление, уничтожение

4.2. Обработка персональных данных осуществляется как с использованием средств автоматизации, так и без использования таких средств.

5. Передача персональных данных третьим лицам

5.1. Персональные данные могут быть переданы третьим лицам в следующих случаях:

  • Платёжным системам для обработки платежей

  • По требованию государственных органов в случаях, предусмотренных законодательством

5.2. Во всех случаях передача данных осуществляется с соблюдением требований законодательства о персональных данных.
